# 🧮 AI Voice Scientific Calculator

An intelligent Scientific Calculator built with Python, Tkinter, SymPy, and Speech Recognition. This calculator understands natural language commands, supports voice input, and provides step-by-step solutions for mathematical expressions and equations.

## 🚀 Features

* Basic arithmetic operations

  * Addition
  * Subtraction
  * Multiplication
  * Division

* Scientific calculations

  * Square Root
  * Powers and Exponents
  * Factorial
  * Trigonometric Functions (sin, cos, tan, cot, sec, cosec)
  * Percentage Calculations

* Voice Recognition

  * Speak mathematical expressions directly
  * Automatic speech-to-expression conversion

* Natural Language Understanding

  * "Add 5 and 10"
  * "Subtract 20 from 50"
  * "Square root of 144"
  * "Factorial of 6"
  * "5 raised to the power 3"

* Step-by-Step Solver

  * Expression simplification
  * Equation solving
  * Detailed calculation process

* User-Friendly GUI

  * Built with Tkinter
  * Easy-to-use scientific calculator interface

## 📦 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ai-voice-scientific-calculator.git
cd ai-voice-scientific-calculator
```

### 2. Install Required Packages

```bash
pip install sympy
pip install SpeechRecognition
pip install word2number
pip install pyaudio
```

Or install everything using:

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
python app.py
```
